# sysboard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `sysboard`, a pure-bash full-screen TUI dashboard showing systemd services (system+user), timers, docker containers, cron jobs, and autostart apps, with actions and a `--report` one-shot mode.

**Architecture:** Single script `scripts/tools/sysboard.sh` (symlinked as `bin/sysboard`) split into: testable collector functions (one per data source, emitting TSV), formatters, a report renderer, and a TUI loop using tput/ANSI alternate screen. Tests mock `systemctl`/`docker`/`crontab` with shell functions (bash resolves functions before PATH binaries).

**Tech Stack:** Bash 5, tput/ANSI, systemctl, docker, crontab. Tests use `tests/test_helper.sh`.

**Spec:** `docs/superpowers/specs/2026-09-26-sysboard-design.md`

**Note:** Per repo workflow, record task progress in `tasks/todo.md` as you go.

## Critical implementation constraints

1. The script MUST end with a main guard so tests can source it:
   ```bash
   if [[ "${BASH_SOURCE[0]}" == "$0" ]]; then
     sb_main "$@"
   fi
   ```
2. Collectors MUST call `systemctl`/`docker`/`crontab` unqualified (never `/usr/bin/systemctl`) so test function-mocks win.
3. `set -uo pipefail` only — NO `set -e` (interactive loop must survive failed commands).
4. Empty-array expansion under `set -u`: use `${arr[@]+"${arr[@]}"}` or ensure arrays are non-empty before expanding (bash 5.2 handles empty `[@]` fine, but be consistent).
5. All external output is captured into variables — nothing raw dumped to the TUI screen.
6. Default paths are overridable via env vars for testing: `SYSBOARD_CRON_D`, `SYSBOARD_USER_AUTOSTART`, `SYSBOARD_SYSTEM_AUTOSTART`.

#!/usr/bin/env bash
# sysboard - TUI dashboard for systemd services, timers, docker, cron, autostart
# Usage: sysboard [--report] [--section NAME] [--no-auto] [--refresh N] [-h]
set -uo pipefail

# ---- colors (mirrors functions/logging.sh) ----
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[0;33m'
BLUE='\033[0;34m'
GRAY='\033[90m'
BOLD='\033[1m'
NC='\033[0m'

# ---- configuration / globals ----
MODE="tui"
SECTION_FILTER=""
AUTO_REFRESH=1
REFRESH_INTERVAL=5
START_SECTION=1

SECTIONS=(system user timers docker cron autostart)
SECTION_LABELS=(System User Timers Docker Cron Autostart)

SB_SECTION=1
SB_SEL=0
SB_ROWS=()
SB_MSG=""
SB_KEY=""
declare -A SB_COUNTS

sb_usage() {
  cat <<'EOF'
sysboard - dashboard for services, timers, docker, cron, autostart

Usage: sysboard [options]

Options:
  --report          print all sections and exit (pretty, colored)
  --section NAME    report mode: show only that section; TUI mode: start on it
                    (system|user|timers|docker|cron|autostart)
  --no-auto         disable auto-refresh (TUI)
  --refresh N       auto-refresh interval in seconds (default 5)
  -h, --help        show this help

TUI keys:
  j/k or arrows  move   1-6/Tab  switch section   R  refresh
  s stop  t start  r restart  e enable/disable  l logs  q quit
EOF
}

sb_section_index() {
  # echoes 1-based index for a section name, or nothing if invalid
  local i=1 name
  for name in "${SECTIONS[@]}"; do
    [[ "$name" == "$1" ]] && { echo "$i"; return 0; }
    i=$((i + 1))
  done
  return 1
}

sb_parse_args() {
  while [[ $# -gt 0 ]]; do
    case "$1" in
      --report)
        MODE="report"
        ;;
      --section)
        if [[ -z "${2:-}" ]] || ! sb_section_index "$2" >/dev/null; then
          echo "sysboard: --section requires one of: ${SECTIONS[*]}" >&2
          return 1
        fi
        SECTION_FILTER="$2"
        START_SECTION=$(sb_section_index "$2")
        shift
        ;;
      --no-auto)
        AUTO_REFRESH=0
        ;;
      --refresh)
        if [[ ! "${2:-}" =~ ^[0-9]+$ || "${2:-0}" -eq 0 ]]; then
          echo "sysboard: --refresh requires a positive integer" >&2
          return 1
        fi
        REFRESH_INTERVAL="$2"
        shift
        ;;
      -h|--help)
        sb_usage
        exit 0
        ;;
      *)
        echo "sysboard: unknown option: $1" >&2
        return 1
        ;;
    esac
    shift
  done
}

sb_main() {
  sb_parse_args "$@" || { sb_usage >&2; return 1; }
  if [[ "$MODE" == "tui" && ! -t 0 && -z "${SYSBOARD_FORCE_TUI:-}" ]]; then
    echo "sysboard: stdin is not a terminal, falling back to report mode" >&2
    MODE="report"
  fi
  if [[ "$MODE" == "report" ]]; then
    sb_render_report
    return $?
  fi
  sb_tui
}

if [[ "${BASH_SOURCE[0]}" == "$0" ]]; then
  sb_main "$@"
fi

# ---- collectors: emit TSV rows, one entry per line ----

# collect_systemd [user] -> ACTIVE<TAB>SUB<TAB>UNIT<TAB>ENABLED
collect_systemd() {
  local scope=()
  [[ "${1:-}" == "user" ]] && scope=(--user)
  local unit state
  declare -A enabled_map=()
  while read -r unit state; do
    [[ -n "$unit" ]] && enabled_map["$unit"]="$state"
  done < <(systemctl "${scope[@]}" list-unit-files --type=service --no-legend 2>/dev/null | awk 'NF{print $1, $2}')
  systemctl "${scope[@]}" list-units --type=service --all --no-legend 2>/dev/null \
    | awk 'NF{print $3 "\t" $4 "\t" $1}' \
    | while IFS=$'\t' read -r active sub unit; do
        printf '%s\t%s\t%s\t%s\n' "$active" "$sub" "$unit" "${enabled_map[$unit]:-static}"
      done
}
```

# collect_timers [user] -> NEXT<TAB>LAST<TAB>UNIT
# Per-unit `systemctl show` instead of parsing list-timers columns
# (column widths vary; "n/a" breaks positional parsing).
collect_timers() {
  local scope=()
  [[ "${1:-}" == "user" ]] && scope=(--user)
  systemctl "${scope[@]}" list-units --type=timer --all --no-legend 2>/dev/null \
    | awk 'NF{print $1}' \
    | while read -r unit; do
        local next last
        next=$(systemctl "${scope[@]}" show "$unit" --property=NextElapseUSecRealtime --value 2>/dev/null)
        last=$(systemctl "${scope[@]}" show "$unit" --property=LastTriggerUSec --value 2>/dev/null)
        printf '%s\t%s\t%s\n' "${next:-n/a}" "${last:-n/a}" "$unit"
      done
}
```

docker_state_from_status() {
  case "$1" in
    Up*)         echo running ;;
    Exited*)     echo exited ;;
    Created*)    echo created ;;
    Restarting*) echo restarting ;;
    Paused*)     echo paused ;;
    *)           echo other ;;
  esac
}

# collect_docker -> STATE<TAB>NAME<TAB>IMAGE<TAB>STATUS<TAB>PORTS
collect_docker() {
  local name image status ports
  while IFS=$'\t' read -r name image status ports; do
    [[ -z "$name" ]] && continue
    printf '%s\t%s\t%s\t%s\t%s\n' \
      "$(docker_state_from_status "$status")" "$name" "$image" "$status" "$ports"
  done < <(docker ps -a --format '{{.Names}}\t{{.Image}}\t{{.Status}}\t{{.Ports}}' 2>/dev/null)
}

# cron_parse_line LINE user|system -> SCHEDULE<TAB>WHO<TAB>COMMAND (rc 1 = skip)
cron_parse_line() {
  local line="$1" src="$2"
  [[ "$line" =~ ^[[:space:]]*(#|$) ]] && return 1
  [[ "$line" =~ ^[[:space:]]*[A-Za-z_][A-Za-z0-9_]*= ]] && return 1
  local first rest who cmd sched
  read -r first rest <<<"$line"
  if [[ "$first" == @* ]]; then
    sched="$first"
    if [[ "$src" == "user" ]]; then
      who="${USER:-$(id -un)}"; cmd="$rest"
    else
      read -r who cmd <<<"$rest"
    fi
  else
    local m h dom mon dow
    read -r m h dom mon dow rest <<<"$line"
    sched="$m $h $dom $mon $dow"
    if [[ "$src" == "user" ]]; then
      who="${USER:-$(id -un)}"; cmd="$rest"
    else
      read -r who cmd <<<"$rest"
    fi
  fi
  printf '%s\t%s\t%s\n' "$sched" "$who" "$cmd"
}

# collect_cron [CRON_D_DIR] -> SOURCE<TAB>SCHEDULE<TAB>WHO<TAB>COMMAND
# SOURCE is "user" or the /etc/cron.d file path.
collect_cron() {
  local cron_d_dir="${1:-${SYSBOARD_CRON_D:-/etc/cron.d}}"
  local out line entry file
  if out=$(crontab -l 2>/dev/null); then
    while IFS= read -r line; do
      if entry=$(cron_parse_line "$line" user); then
        printf 'user\t%s\n' "$entry"
      fi
    done <<<"$out"
  fi
  for file in "$cron_d_dir"/*; do
    [[ -f "$file" && -r "$file" ]] || continue

      if entry=$(cron_parse_line "$line" system); then

autostart_parse_desktop() {
  local file="$1" scope="$2"
  local name="" exec_cmd="" hidden="false" autostart="true" key value
  while IFS='=' read -r key value; do
    key="${key//[[:space:]]/}"
    case "$key" in
      Name) name="$value" ;;
      Exec) exec_cmd="$value" ;;
      Hidden) hidden="$value" ;;
      X-GNOME-Autostart-enabled) autostart="$value" ;;
    esac
  done <"$file"
  local state="enabled"
  [[ "$hidden" == "true" ]] && state="hidden"
  [[ "$autostart" == "false" ]] && state="disabled"
  printf '%s\t%s\t%s\t%s\t%s\n' \
    "$state" "${name:-$(basename "$file" .desktop)}" "$exec_cmd" "$scope" "$file"
}

sb_input() {
  # read one key from /dev/tty when available, else stdin
  local t=()
  [[ $AUTO_REFRESH -eq 1 ]] && t=(-t "$REFRESH_INTERVAL")
  if [[ -r /dev/tty ]]; then
    IFS= read -rsn1 ${t[@]+"${t[@]}"} "$1" </dev/tty || true
  else
    IFS= read -rsn1 ${t[@]+"${t[@]}"} "$1" || true
  fi
}

sb_read_key() {
  SB_KEY=""
  sb_input SB_KEY
  if [[ "$SB_KEY" == $'\e' ]]; then
    local seq=""
    if [[ -r /dev/tty ]]; then
      IFS= read -rsn2 -t 0.1 seq </dev/tty || true
    else
      IFS= read -rsn2 -t 0.1 seq || true
    fi
    case "$seq" in
      '[A') SB_KEY='k' ;;
      '[B') SB_KEY='j' ;;
      *)    SB_KEY='' ;;
    esac
  fi
}

sb_refresh_counts() {

    tput cnorm 2>/dev/null || true
    sudo systemctl "$verb" "$unit"
    rc=$?
    tput civis 2>/dev/null || true
    tput smcup 2>/dev/null || true
  else
    systemctl --user "$verb" "$unit"
    rc=$?
  fi
  SB_MSG="$verb $unit -> exit $rc"
  sb_refresh_counts
  sb_load_section
}

sb_toggle_enable() {
  local unit scope=() cur
  unit=$(sb_selected_unit)
  [[ -z "$unit" ]] && return 1
  case "$(sb_section_name)" in
    user)   scope=(--user) ;;
    timers) [[ -n "$(sb_unit_scope "$unit")" ]] && scope=(--user) ;;
  esac
  cur=$(systemctl "${scope[@]}" is-enabled "$unit" 2>/dev/null || echo unknown)
  if [[ "$cur" == "enabled" ]]; then
    sb_systemd_action disable
  else
    sb_systemd_action enable
  fi
}

sb_docker_action() {
  local verb="$1" name
  name=$(sb_selected_unit)
  [[ -z "$name" ]] && return 1
  sb_confirm "docker $verb $name?" || return 1
  docker "$verb" "$name" &>/dev/null
  local rc=$?
  SB_MSG="docker $verb $name -> exit $rc"
  sb_refresh_counts
  sb_load_section
}

sb_show_logs() {
  local unit section scope=()
  section=$(sb_section_name)
  unit=$(sb_selected_unit)
  [[ -z "$unit" ]] && return 1
  sb_confirm "show logs for $unit?"
  tput rmcup 2>/dev/null || true
  tput cnorm 2>/dev/null || true
  if [[ "$section" == "docker" ]]; then
    docker logs --tail 200 "$unit" | "${PAGER:-less}"
  else
    case "$section" in
      user)   scope=(--user) ;;
      timers) [[ -n "$(sb_unit_scope "$unit")" ]] && scope=(--user) ;;
    esac
    journalctl "${scope[@]}" -u "$unit" -n 200 --no-pager | "${PAGER:-less}"
  fi
  tput civis 2>/dev/null || true
  tput smcup 2>/dev/null || true
}

sb_handle_action() {
  SB_MSG=""
  case "$(sb_section_name)" in
    system|user|timers)
      case "$1" in
        s) sb_systemd_action stop ;;
        t) sb_systemd_action start ;;
        r) sb_systemd_action restart ;;
        e) sb_toggle_enable ;;
        l) sb_show_logs ;;
      esac
      ;;
    docker)
      case "$1" in
        s) sb_docker_action stop ;;
        t) sb_docker_action start ;;
        r) sb_docker_action restart ;;
        l) sb_show_logs ;;
        *) SB_MSG="read-only action" ;;
      esac
      ;;
    *)
      SB_MSG="read-only section"
      ;;
  esac
}

sb_help_overlay() {
  local box=(
    'sysboard keys'
    ''
    '  j/k or arrows   move selection'
    '  1-6 or Tab      switch section'
    '  g / G           jump to top / bottom'
    '  s / t / r       stop / start / restart'
    '  e               toggle enable/disable (systemd)'
    '  l               view logs (journalctl / docker logs)'
    '  R               refresh now'
    '  q               quit'
    ''
    '  cron and autostart sections are read-only'
  )
  local lines cols i
  lines=$(tput lines 2>/dev/null || echo 24)
  cols=$(tput cols 2>/dev/null || echo 80)
  local top=$(((lines - ${#box[@]}) / 2))
  printf '\033[H'
  for ((i = 0; i < top; i++)); do printf '\n'; done
  printf '%*s┌─ help ─┐\n' $(((cols - 10) / 2)) ''
  for i in "${box[@]}"; do
    printf '%*s│ %s │\n' $(((cols - 10) / 2)) '' "$(sb_truncate "$i" $((cols - 16)))"
  done
  printf '%*s└────────┘\n' $(((cols - 10) / 2)) ''
  printf 'press any key...'
  local key=""
  sb_input key
}

```markdown
# sysboard

Terminal dashboard for everything running or scheduled on the machine:
systemd services (system + user), timers, docker containers, cron jobs,
and autostart apps.

## Usage

    sysboard                  # interactive TUI
    sysboard --report         # one-shot pretty report
    sysboard --section docker # report: only docker; TUI: start on docker tab
    sysboard --no-auto        # disable auto-refresh
    sysboard --refresh 10     # refresh every 10s

Falls back to `--report` mode when stdin is not a terminal.

## Keys (TUI)

| Key | Action |
|---|---|
| `j`/`k`, arrows | move selection (`g`/`G` top/bottom) |
| `1`-`6`, `Tab` | switch section |
| `s` / `t` / `r` | stop / start / restart (systemd, docker) |
| `e` | toggle enable/disable (systemd) |
| `l` | view logs (`journalctl` / `docker logs`, via `$PAGER`) |
| `R` | refresh now |
| `?` | help overlay |
| `q` | quit |

System-level systemd actions prompt for sudo (the TUI leaves the alternate
screen for the password prompt, then redraws). Docker actions assume the
user is in the `docker` group. Cron and autostart sections are read-only.

## Sections

1. **System services** — `systemctl list-units` + enabled state from `list-unit-files`
2. **User services** — same, `--user`
3. **Timers** — user + system, next/last trigger via `systemctl show`
4. **Docker** — `docker ps -a` (all states)
5. **Cron** — `crontab -l` + `/etc/cron.d/*`
6. **Autostart** — `~/.config/autostart` + `/etc/xdg/autostart` (system entries dimmed)

## Testing

    bash tests/sysboard_test.sh

Collectors are unit-tested with function mocks (`systemctl`, `docker`,
`crontab` are overridden as shell functions; bash resolves functions before
PATH binaries). Path overrides for tests: `SYSBOARD_CRON_D`,
`SYSBOARD_USER_AUTOSTART`, `SYSBOARD_SYSTEM_AUTOSTART`,
`SYSBOARD_FORCE_TUI=1`.
```
